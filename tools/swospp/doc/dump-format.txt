SWOS++ variable dump format
===========================

This document is an early design specification for the variable-dump facility.

Basic types:
    - byte
    - word
    - dword

Basic-type modifiers:
    - signed
    - unsigned

Compound types:
    - arrays of basic types
    - structures composed of basic types

Additional output:
    - hexadecimal dump

Variables to be printed should ideally be kept in a static array terminated by
-1 or another special code. The array is best defined in an assembly file,
where all SWOS variables are directly accessible. The format should resemble
printf.

Output options (flags):
    - decimal
    - hexadecimal
    - octal
    - binary
    - signed
    - unsigned (ignored for non-decimal output; signed and unsigned share one
                bit, and unsigned is the default)
    - left-aligned
    - right-aligned (these share one bit; left-aligned is the default)
    - sign prefix
    - pad with zeroes
    - prefix a positive signed value with a space
    - prefix a hexadecimal value with 0x

PrintString() alignment flags:
    #define NO_ALIGNMENT      0
    #define ALIGN_LEFT        1 << ALIGN_LEFT_BIT
    #define ALIGN_RIGHT       1 << ALIGN_RIGHT_BIT
    #define ALIGN_CENTERX     1 << ALIGN_CENTERX_BIT
    #define ALIGN_UP          1 << ALIGN_UP_BIT
    #define ALIGN_DOWN        1 << ALIGN_DOWN_BIT
    #define ALIGN_CENTERY     1 << ALIGN_CENTERY_BIT

    #define ALIGN_CENTER      ALIGN_CENTERX | ALIGN_CENTERY
    #define ALIGN_UPRIGHT     ALIGN_RIGHT | ALIGN_UP
    #define ALIGN_UPLEFT      ALIGN_LEFT | ALIGN_UP
    #define ALIGN_DOWNRIGHT   ALIGN_DOWN | ALIGN_RIGHT
    #define ALIGN_DOWNLEFT    ALIGN_DOWN | ALIGN_LEFT

The data type comes first, followed by the output format, optional width,
optional precision, and finally a pointer to the value. A pointer to the
value's name may optionally follow.

    {type flags ptr-to-data [.ptr-to-name]} '\0'

The first byte (type) may be:

    c - character
    b - byte
    w - word
    d - dword
    s - null-terminated character string
    f - signed-word fixed-point number
    m - mantissa of a fixed-point number
    p - pointer, printed as a dword without dereferencing it
    a - array, followed by the number of elements to print
    t - structure, followed by the element count and an array of element types
    n - no operation, for alignment if required
    u - hexadecimal dump; immediately followed by a dword dump length, then
        two words specifying the number of bytes per row and column, followed
        by flags; in this case the data pointer is the starting address
    i - output for the following field is disabled; this allows variables to
        be enabled and disabled without deleting their descriptions

Width may be prefixed with an asterisk. In that case it is followed by a
pointer to a short containing the width. If precision is prefixed with a
semicolon, its value is obtained using the same rule. Coordinates are two
words; when present, output is drawn at that location.

Example: print a signed byte

    db 'b'          ; type - byte
    dw SIGNED       ; flags - signed byte
    db '%'          ; width is present
    dw 6            ; print in six positions
    dd my_byte      ; pointer to data; no precision
    db '.'          ; pointer to the data name follows
    dd my_byte_str  ; pointer to the data name

Example: print a string

    db 's'          ; type - string
    dw 0            ; no flags
    db '.'          ; precision is present; no width
    dw 255          ; maximum of 255 characters
    dd my_string    ; pointer to data
