v0.99.2026 - 06.09.2026.
       + added animation mode for previewing player and goalkeeper animation sequences
       + added playback controls, direction selection, zoom, pause and slow motion
       + animation data is generated from the shared SWOS animation tables
       * updated English and Serbian documentation for animation mode
       * removed the obsolete DirectDraw/fullscreen implementation
       * modernized the Visual Studio project and cleaned up legacy Windows-specific code

v0.99 - 15.12.2022.
       + added "tile painting", right click on a tile and drag, it will paint the initial tile over the dragged ones
           | it's available from keyboard too, shift+arrows can be also used
           | "master" tile can be selected with ctrl+left click, or ctrl+enter on keyboard
       + tiles can be mass inserted with shift+insert, it will look for files with pattern "pt<pitchNo>-<tileNo>.bmp
       + left double-click on a tile (or g key) enters pattern number directly (to the selected tile if pressing g)
       + holding middle mouse button (or tab on keyboard) shows tile number even if tile number display is off
       + ctrl+o optimizes pitch, removes unused tiles and renumbers existing ones in order of appearance
       + ctrl+r discards changes and reverts to last saved pitch
       + ctrl+s saves pitch changes, ctrl+shift+s force saves even if no changes
       + c for mass tile replace: enter number which will replace all instances of selected tile on the pitch
       + undo/redo added for operations that change pitch or patterns
       + patterns can be also changed by holding ctrl and mouse wheel scrolling (same as ctrl+up/down)
       + ctrl+insert adds new empty tile to the end in the tile mode
       + tiles can be highlighted: ctrl-shift left click (or press 'H' in tile mode)
       + alt-left click on a tile in pitch mode switches to tile mode and displays the clicked tile
       + tiles can now be deleted from the pitch view too
       + usage count display for tiles in tile modes (specially marked if unused)
       + usage count display for tiles in pitch mode (toggles number display)
       + pitch scrolling on mouse wheel
       + panning the pitch with left click drag
       * fixed excessive CPU usage in pitch mode
       * changed pattern mode to be consistent with pitch mode: up increases pattern number, down decreases
       * fixed a bug with pattern insertion when searching for wrong filename
       * moved pattern number by a pixel right & down on the pitch, so it's easier to read now
       * fixed window positioning and screen edge snapping
       * lot of small fixes (e.g. window centering and moving fixed, custom cursor behaves properly now)
       - removed some obsolete or unfit features
