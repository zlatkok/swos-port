                           SWPE - SWOS Picture Editor
                           ==========================

This program is distributed as part of the SWOS Port project. Current release
archives can be downloaded from the project's GitHub Releases page:
https://github.com/zlatkok/swos-port/releases

For community discussion, visit sensiblesoccer.de or Discord:
https://discord.gg/7ddcjuWA

=== Installation and uninstallation

Simply copy swpe.exe to SWOS dir. Every file that the program requires will
already be there (presuming that your SWOS installation is OK). To remove it,
just delete swpe.exe. Also be sure to read documentation before trying to
change anything in SWOS.

=== System requirements

Program is tested on Windows 10, but will probably work on higher/lower
versions. Resource requirements are very low so any system capable of running
Windows will suffice. Fullscreen mode is broken, and likely to stay that way.
